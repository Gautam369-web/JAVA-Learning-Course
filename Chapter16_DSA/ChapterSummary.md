# 🟢 Chapter Summary — Chapter 16: Data Structures & Algorithms (DSA)

## 📋 What This Chapter Covers
DSA is the **language of problem-solving**. Every tech interview, competitive programming challenge, and efficient software system relies on DSA. This chapter teaches you how to think algorithmically — choosing the right data structure and algorithm for any problem.

## 💡 5 Key Takeaways
1. **Know Big-O** — always ask: "What is the time complexity of this solution?"
2. **Two-pointer and sliding window solve ~30% of array problems** — master them first.
3. **Binary search halves the search space each time** — O(log n) is powerfully fast.
4. **Recursion needs a base case** — without it, you get a StackOverflowError (infinite recursion).
5. **HashMap is your best friend for frequency/lookup problems** — O(1) access changes everything.
