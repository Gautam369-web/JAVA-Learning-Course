# Chapter 16 - Full Practice Questions

## Problem 1 - Beginner: Find Maximum Number

**Problem Statement**  
Given an array of integers, find and print the largest number.

**Input Format**
```text
n
number1 number2 ... numberN
```

**Output Format**
```text
Maximum: <largestNumber>
```

**Sample Input**
```text
5
10 45 3 99 20
```

**Sample Output**
```text
Maximum: 99
```

## Problem 2 - Intermediate: Valid Parentheses

**Problem Statement**  
Given a string containing only `(` and `)`, check whether the parentheses are balanced. A string is balanced if every opening bracket has a matching closing bracket in the correct order.

**Input Format**
```text
bracketString
```

**Output Format**
```text
Valid
```

or

```text
Invalid
```

**Sample Input**
```text
(()())
```

**Sample Output**
```text
Valid
```

## Problem 3 - Advanced: Breadth-First Search

**Problem Statement**  
Given an undirected graph and a starting node, print the BFS traversal order. Visit neighbors in the order they are given.

**Input Format**
```text
nodes
edges
u1 v1
u2 v2
...
startNode
```

**Output Format**
```text
BFS: node1 node2 node3 ...
```

**Sample Input**
```text
5
4
1 2
1 3
2 4
3 5
1
```

**Sample Output**
```text
BFS: 1 2 3 4 5
```
