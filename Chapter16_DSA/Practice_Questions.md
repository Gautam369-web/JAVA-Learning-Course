# Chapter 16 - Practice Questions

These problems start with loops and grow into interview-style DSA.

---

## Problem 1 - Maximum Number
Find the largest number in an integer array.

## Problem 2 - Count Vowels
Count vowels in a string.

## Problem 3 - Reverse Array
Reverse an array without using another array.

## Problem 4 - Linear Search
Return the index of a target value, or `-1` if it is missing.

## Problem 5 - Binary Search
Implement binary search on a sorted array.

## Problem 6 - Valid Parentheses
Use a stack to check whether brackets are balanced.

## Problem 7 - Queue Simulation
Simulate a customer queue with add and serve operations.

## Problem 8 - Recursion Factorial
Write recursive factorial and explain the base case.

## Problem 9 - Sorting
Implement bubble sort, then explain why it is `O(n^2)`.

## Problem 10 - Advanced: BFS
Given a graph as an adjacency list, perform breadth-first search from a starting node.

## Problem 11 - Advanced: Word Frequency
Count how many times each word appears in a sentence using `HashMap`.

## Problem 12 - Advanced: Top K Numbers
Use a priority queue to find the largest `k` numbers in an array.
