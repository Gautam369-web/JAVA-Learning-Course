# Chapter 19 - Practice Questions

These problems move from local logs to real API communication.

---

## Problem 1 - Logging Levels
Give one example each for `INFO`, `WARN`, and `ERROR`.

## Problem 2 - Logger Setup
Create a class with a `Logger` and log "Application started".

## Problem 3 - JSON Reading
Write a JSON object for a product with id, name, price, and available fields.

## Problem 4 - Java Object to JSON
Create a `Product` class that matches your JSON.

## Problem 5 - Jackson Serialization
Use Jackson to convert a `Product` object to JSON.

## Problem 6 - Jackson Deserialization
Convert a JSON string into a `Product` object.

## Problem 7 - HTTP Status Codes
Explain `200`, `201`, `400`, `404`, and `500`.

## Problem 8 - GET Request
Use Java `HttpClient` to send a GET request and print status code.

## Problem 9 - Advanced: POST JSON
Send JSON in a POST request using Java `HttpClient`.

## Problem 10 - Advanced: API Error Handling
Write logic that treats `2xx`, `4xx`, and `5xx` responses differently.
