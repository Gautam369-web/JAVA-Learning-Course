# Chapter 17 - Practice Questions

These questions help you use modern Java features responsibly.

---

## Problem 1 - var
Create local variables using `var` for name, age, and a list of marks.

## Problem 2 - Record
Create a `record` named `Book` with `title`, `author`, and `price`.

## Problem 3 - Switch Expression
Use a switch expression to convert a number from 1 to 7 into a weekday name.

## Problem 4 - Text Block
Create a JSON string using a text block.

## Problem 5 - Pattern Matching
Write a method that accepts `Object` and prints string length only if it is a `String`.

## Problem 6 - Record Validation
Create a `Student` record that rejects blank names in its compact constructor.

## Problem 7 - Sealed Types
Create a sealed interface `Shape` with permitted classes `Circle` and `Rectangle`.

## Problem 8 - Advanced: Payment Model
Use sealed classes and switch expressions to calculate payment fee by payment type.

## Problem 9 - Advanced: Refactor Old POJO
Convert an old immutable class with fields, constructor, getters, `equals`, and `hashCode` into a record.

## Problem 10 - Advanced: When Not to Use var
Write three examples where `var` makes code less readable.
