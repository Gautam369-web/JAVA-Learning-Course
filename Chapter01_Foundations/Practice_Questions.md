# Chapter 1 Practice Questions

This chapter covers the absolute basics: printing, variables, and taking user input.

---

## Problem 1 – Sum of Two Numbers
**Problem Statement**: Read two integers `a` and `b` from standard input and output their sum.

**Sample Input**:
```text
10 20
```
**Sample Output**:
```text
30
```

---

## Problem 2 – Even or Odd
**Problem Statement**: Read an integer `n` and print `Even` if it is divisible by 2, otherwise `Odd`.

**Sample Input**:
```text
7
```
**Sample Output**:
```text
Odd
```

---

## Problem 3 – Temperature Converter
**Problem Statement**: Convert a temperature from Celsius to Fahrenheit using the formula `F = C * 9/5 + 32`.

**Sample Input**:
```text
37
```
**Sample Output**:
```text
98.6
```

---

### Instructions for Solving:
1. Create a new `.java` file for each problem.
2. Use `Scanner` to read values from the console.
3. Verify your results against the sample cases provided.
