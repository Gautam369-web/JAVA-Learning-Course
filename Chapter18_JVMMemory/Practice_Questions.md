# Chapter 18 - Practice Questions

These questions build mental clarity about what Java does while running.

---

## Problem 1 - JVM Flow
Write the flow from `.java` file to running program.

## Problem 2 - Stack vs Heap
Classify local primitives, object references, and objects as stack or heap.

## Problem 3 - Object Reference
Create two references pointing to the same object and show that changing one affects the other.

## Problem 4 - Eligible for GC
Write a code example where an object becomes eligible for garbage collection.

## Problem 5 - Stack Overflow
Write a recursive method that would eventually cause `StackOverflowError`. Then fix it with a base case.

## Problem 6 - Memory Leak Example
Create a static list that keeps growing. Explain why it can become a leak.

## Problem 7 - String Pool
Compare two string literals using `==` and `.equals`.

## Problem 8 - Advanced: Heap Pressure
Write code that creates many objects in a loop and explain why memory usage increases.

## Problem 9 - Advanced: Diagnose Memory Problem
An app becomes slower after running for hours. List likely causes and investigation steps.

## Problem 10 - Advanced: Immutability
Explain why immutable objects are usually safer in multithreaded code.
