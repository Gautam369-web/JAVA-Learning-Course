# Chapter 20 - Practice Questions

These questions grow from naming habits to reusable design patterns.

---

## Problem 1 - Rename Bad Variables
Improve variable names: `x`, `d`, `a1`, `temp`.

## Problem 2 - Extract Method
Take a long method that validates and saves a user. Split it into smaller methods.

## Problem 3 - Single Responsibility
Explain why a class that reads files, calculates salary, and sends emails has too many responsibilities.

## Problem 4 - Factory Pattern
Create a notification factory that returns email or SMS notification objects.

## Problem 5 - Builder Pattern
Create a `User` builder with name, email, and phone.

## Problem 6 - Strategy Pattern
Create discount strategies: no discount, festival discount, and student discount.

## Problem 7 - MVC
Separate a student app into model, view, and controller responsibilities.

## Problem 8 - Code Smell Detection
List problems in code with duplicated if-else blocks and long methods.

## Problem 9 - Advanced: Refactor Switch
Replace a large payment-type switch with strategy classes.

## Problem 10 - Advanced: SOLID Review
Review a class and identify which SOLID principles it violates.
