# Chapter 25 - Practice Questions

These tasks are project milestones. Complete them in order to build the final backend capstone.

---

## Problem 1 - Requirements
Write functional requirements for students, courses, and enrollments.

## Problem 2 - Database Design
Design tables for students, courses, and enrollments.

## Problem 3 - Project Setup
Create a Maven Spring Boot project with web, validation, JPA, and database dependencies.

## Problem 4 - Student CRUD
Implement full CRUD for students.

## Problem 5 - Course CRUD
Implement full CRUD for courses.

## Problem 6 - Enrollment
Allow a student to enroll in a course.

## Problem 7 - Validation
Reject blank names, invalid emails, and duplicate enrollments.

## Problem 8 - Error Handling
Return consistent JSON errors for missing resources and invalid input.

## Problem 9 - Testing
Write service tests with Mockito and controller tests with MockMvc.

## Problem 10 - Documentation
Write a README with setup instructions, endpoints, and sample requests.

## Problem 11 - Advanced: Pagination
Add pagination to list students and courses.

## Problem 12 - Advanced: Deployment Prep
Prepare the app to run from environment variables and package it as a JAR.
