## Common Misconceptions

### Gap 1: Theoretical vs Practical Understanding
Many students can recite the definition but struggle to USE the technology.
**Fix:** Always write code. Don't just read examples — type them yourself.

### Gap 2: Isolation vs Integration
This technology works WITH other Java features, not in isolation.
**Fix:** Look for how this chapter connects to OOP, Collections, and Exception Handling.

### Gap 3: Tool vs Concept Confusion
Don't confuse the tool (library/framework) with the underlying concept.
**Fix:** Understand WHY this tool exists and what problem it solves before learning HOW to use it.
