# Chapter 21 - Practice Questions

These questions introduce Spring Boot from first app to layered design.

---

## Problem 1 - Spring Boot Purpose
Write why Spring Boot is useful compared to manually configuring a Java web app.

## Problem 2 - Main Class
Create a basic Spring Boot main class with `@SpringBootApplication`.

## Problem 3 - Service
Create a `GreetingService` with a method that returns a welcome message.

## Problem 4 - Controller
Create a REST controller with `GET /hello`.

## Problem 5 - Constructor Injection
Inject `GreetingService` into the controller using constructor injection.

## Problem 6 - Properties
Set the server port to `9090` using `application.properties`.

## Problem 7 - Layers
Explain controller, service, and repository responsibilities.

## Problem 8 - Advanced: Replace Manual Object Creation
Refactor code that uses `new UserService()` inside a controller to dependency injection.

## Problem 9 - Advanced: Bean Conflict
Explain what can happen if two beans of the same type exist.

## Problem 10 - Advanced: Package Design
Design packages for a Spring Boot library API.
