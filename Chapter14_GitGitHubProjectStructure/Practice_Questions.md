# Chapter 14 - Practice Questions

These problems move from basic Git commands to organizing a small Java project professionally.

---

## Problem 1 - Git Vocabulary
Explain these terms in your own words: repository, commit, branch, remote, pull request.

## Problem 2 - First Repository
Create a new folder, initialize Git, add a `README.md`, and make your first commit.

## Problem 3 - Git Status Reading
Create, modify, and delete files. Run `git status` after each action and write what changed.

## Problem 4 - Java Package
Create a package named `com.course.student` and place a `Student` class inside it.

## Problem 5 - Import Practice
Create another package named `com.course.app`. Import and use the `Student` class from `main`.

## Problem 6 - .gitignore
Create a `.gitignore` that ignores `.class`, `target/`, `build/`, and IDE folders.

## Problem 7 - Branch Workflow
Create a branch named `feature/student-class`, make a commit, and merge it back into `main`.

## Problem 8 - Mini Project Structure
Design a project layout for a library app with packages for `book`, `user`, and `app`.

## Problem 9 - Advanced: Pull Request Description
Write a pull request description for adding a `Student` class. Include summary, tests, and risk.

## Problem 10 - Advanced: Refactor Flat Files
Take three Java files in one folder and reorganize them into meaningful packages.
