# Chapter 15 - Practice Questions

These questions teach build tools from simple project setup to dependency and test workflows.

---

## Problem 1 - Build Tool Meaning
Write three things Maven or Gradle can automate for a Java project.

## Problem 2 - Maven Layout
Create the folders `src/main/java` and `src/test/java`. Explain why Maven uses this layout.

## Problem 3 - Basic pom.xml
Write a minimal `pom.xml` with `groupId`, `artifactId`, and `version`.

## Problem 4 - Compile Command
Run or explain what `mvn compile` does.

## Problem 5 - Add JUnit
Add JUnit 5 as a test dependency in `pom.xml`.

## Problem 6 - Package App
Explain what `mvn package` creates and where Maven stores the result.

## Problem 7 - Dependency Research
Find the Maven coordinates for Jackson Databind and add them to a `pom.xml`.

## Problem 8 - Gradle Comparison
Write the same Java dependency in Maven XML and Gradle syntax.

## Problem 9 - Advanced: Multi-Module Thinking
Design a Maven multi-module project with `api`, `service`, and `data` modules.

## Problem 10 - Advanced: Build Failure Diagnosis
A Maven test fails during `mvn package`. Explain how you would investigate it.
