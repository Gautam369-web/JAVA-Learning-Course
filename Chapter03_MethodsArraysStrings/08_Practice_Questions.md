# Chapter 3 – Practice Questions (Methods, Arrays & Strings)

Test your ability to organize code into methods and manipulate data structures.

---

## Problem 1 – Area of a Circle (Methods)
**Problem Statement**: Write a method `calculateArea(double radius)` that returns the area of a circle. Call this method from `main` with a radius provided by the user.

**Sample Input**:
```text
7
```
**Sample Output**:
```text
153.93804002589985
```

---

## Problem 2 – Maximum of Three (Methods)
**Problem Statement**: Create a method `findMax(int a, int b, int c)` that returns the largest of three integers.

**Sample Input**:
```text
12 45 23
```
**Sample Output**:
```text
45
```

---

## Problem 3 – Reverse a String (Strings)
**Problem Statement**: Take a String input from the user and print it in reverse order.

**Sample Input**:
```text
Java
```
**Sample Output**:
```text
avaJ
```

---

## Problem 4 – Vowel Counter (Strings)
**Problem Statement**: Write a program that counts the number of vowels (`a, e, i, o, u`) in a given string.

**Sample Input**:
```text
Hello World
```
**Sample Output**:
```text
Vowels: 3
```

## Problem 5 – Sum of Array (Arrays)
**Problem Statement**: Create an array of 5 integers. Use a loop to calculate and print the sum of all elements.

**Sample Input**:
```text
10 20 30 40 50
```
**Sample Output**:
```text
Sum: 150
```

## Problem 6 – Search in Array (Arrays)
**Problem Statement**: Create an array of 5 names. Ask the user for a name and check if it exists in the array.

**Sample Input**:
```text
Input Name: Rahul
```
**Sample Output**:
```text
Rahul found in the list!
```

---

## Problem 7 – Row Sum (2D Arrays)
**Problem Statement**: Create a 2x2 matrix. Calculate and print the sum of the first row and the sum of the second row separately.

**Sample Input**:
```text
1 2
3 4
```
**Sample Output**:
```text
Row 0 Sum: 3
Row 1 Sum: 7
```

---

## Problem 8 – Matrix Diagonal (2D Arrays)
**Problem Statement**: Create a 3x3 matrix and print the elements of the main diagonal (top-left to bottom-right).

**Sample Input**:
```text
1 2 3
4 5 6
7 8 9
```
**Sample Output**:
```text
Diagonal: 1 5 9
```

---

### Instructions for Solving:
1. For Method problems, ensure the logic is inside a separate method, not just in `main`.
2. For String problems, explore methods like `charAt()` and `toLowerCase()`.
3. Test your code with different inputs to ensure it works in all cases!
